JavaScript কোডিংয়ের চাবিকাঠি: কন্ডিশনাল স্টেটমেন্টস ও লুপস 🚀

জাভাস্ক্রিপ্ট প্রোগ্রামিংয়ের প্রাণ হলো কন্ডিশনাল স্টেটমেন্টস এবং লুপস। এগুলো ছাড়া ডাইনামিক ও ইন্টারেক্টিভ ওয়েবসাইট বা অ্যাপ তৈরি করা সম্ভব নয়। আসুন বুঝে নিই কীভাবে এই টুলগুলো আপনার কোডকে স্মার্ট ও দক্ষ করে তোলে।

🎯 কন্ডিশনাল স্টেটমেন্টস: প্রোগ্রামের সিদ্ধান্ত নেওয়ার ক্ষমতা

কন্ডিশনাল স্টেটমেন্টস প্রোগ্রামকে বিভিন্ন শর্তের ভিত্তিতে সিদ্ধান্ত নিতে সাহায্য করে। এটি অনেকটা ট্রাফিক সিগন্যালের মতো - সবুজ আলো হলে গাড়ি চলে, লাল আলো হলে থেমে যায়।

১. if স্টেটমেন্ট (সবচেয়ে বেসিক)

একটি শর্ত সত্য (true) হলে নির্দিষ্ট কোড ব্লক রান করানোর জন্য if ব্যবহার করা হয়।

```javascript
let score = 85;
if (score > 80) {
    console.log("Great job!");
}
```

২. if...else স্টেটমেন্ট (দুইটি পছন্দের মধ্যে একটি)

একটি শর্ত সত্য হলে এক কোড ব্লক, মিথ্যা হলে অন্য কোড ব্লক রান হবে।

```javascript
let age = 15;
if (age >= 18) {
    console.log("You are eligible to vote!");
} else {
    console.log("You are not eligible to vote yet.");
}
```

৩. if...else if...else ল্যাডার (একাধিক শর্ত)

একাধিক শর্ত পরীক্ষা করার জন্য এটি ব্যবহার করা হয়। প্রথম যে শর্ত সত্য হবে, তার কোড ব্লক রান হবে এবং বাকিগুলো উপেক্ষা করা হবে।

```javascript
let score = 75;

if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F");
}
```

৪. switch স্টেটমেন্ট (বিশেষ ক্ষেত্রে ব্যবহার)

একটি এক্সপ্রেশন বা ভেরিয়েবলের মান একাধিক সম্ভাব্য কেসের সাথে মিলিয়ে দেখা হয়। if...else if লম্বা চেইনের বিকল্প হিসেবে switch ব্যবহার করলে কোড বেশি পড়তে সুবিধা হয়।

```javascript
let day = 3;
let dayName;

switch (day) {
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    case 3:
        dayName = "Wednesday";
        break;
    default:
        dayName = "Invalid day";
}

console.log(dayName); // Output: Wednesday
```

⚠️ মনে রাখবেন: switch স্টেটমেন্টে প্রতিটি case এর পরে break ব্যবহার না করলে পরবর্তী সব case গুলোও রান হবে (fall-through)।

৫. টারনারি অপারেটর (এক লাইনের if...else)

সাধারণ if...else এর সংক্ষিপ্ত রূপ, সাধারণত ভেরিয়েবলে মান অ্যাসাইন করতে ব্যবহৃত হয়।

```javascript
let score = 72;
let result = score > 50 ? 'Pass' : 'Fail';
console.log(result); // Output: Pass
```

🔁 লুপস: কোডের পুনরাবৃত্তি

একই কাজ বারবার করতে লুপস ব্যবহার করা হয়, যেমন: অ্যারের সব আইটেম দেখানো, বা নির্দিষ্ট সংখ্যক বার কোনো অপারেশন করা।

১. for লুপ (যখন পুনরাবৃত্তির সংখ্যা জানা থাকে)

```javascript
for (let i = 0; i < 5; i++) {
    console.log("Number:", i);
}
```

কিভাবে কাজ করে:

· let i = 0; - লুপ শুরুতে একবার রান হয়
· i < 5; - প্রতিবার লুপ শুরু হওয়ার আগে শর্ত চেক করা হয়
· i++ - প্রতিবার লুপ শেষে রান হয়

২. while লুপ (যখন শর্ত সত্য হওয়া পর্যন্ত চালাতে হয়)

```javascript
let i = 0;
while (i < 5) {
    console.log("Counting:", i);
    i++;
}
```

৩. do...while লুপ (অন্তত একবার রান নিশ্চিত করতে)

```javascript
let i = 0;
do {
    console.log("Value:", i);
    i++;
} while (i < 5);
```

৪. for...of লুপ (অ্যারে বা স্ট্রিং-এর জন্য)

```javascript
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
    console.log(fruit);
}
```

৫. for...in লুপ (অবজেক্টের প্রপার্টিগুলোর জন্য)

```javascript
const person = { name: "Alex", age: 36 };
for (const key in person) {
    console.log(key, ":", person[key]);
}
```

লুপ কন্ট্রোল: break এবং continue

· break - লুপ পুরোপুরি থামিয়ে দেয়
· continue - বর্তমান ইটারেশন ছেড়ে পরবর্তী ইটারেশনে চলে যায়

```javascript
for (let i = 0; i < 10; i++) {
    if (i === 5) break;      // লুপ থেকে বের হয়ে যাবে যখন i=5
    if (i % 2 === 0) continue; // জোড় সংখ্যা হলে বাকি কোড রান হবে না
    console.log(i);
}
```

🛠️ কখন কোন টুল ব্যবহার করবেন?

if...else if...else ব্যবহার করুন যখন:

· একটি ভেরিয়েবলকে একাধিক মান বা রেঞ্জের সাথে তুলনা করছেন
· শর্তগুলো জটিল এক্সপ্রেশন ব্যবহার করে (লজিকাল অপারেটর &&, ||, ! সহ)

switch ব্যবহার করুন যখন:

· একটি এক্সপ্রেশন বা ভেরিয়েবলকে অনেকগুলো নির্দিষ্ট মানের সাথে তুলনা করছেন
· কোডের পড়ার সুবিধা বেশি দরকার (দীর্ঘ if...else if চেইনের বিকল্প)

টারনারি অপারেটর ব্যবহার করুন যখন:

· সহজ দুই-পথের সিদ্ধান্ত নিচ্ছেন
· একটি ভেরিয়েবলে শর্তসাপেক্ষে মান অ্যাসাইন করছেন

লুপের নির্বাচন:

· for - পুনরাবৃত্তির সংখ্যা জানা থাকলে
· while - পুনরাবৃত্তির সংখ্যা না জানা থাকলে, কিন্তু একটি শর্ত সত্য হওয়া পর্যন্ত চালাতে হলে
· for...of - অ্যারে বা ইটারেবল অবজেক্টের আইটেম নিয়ে কাজ করতে

💡 প্র্যাকটিকাল উদাহরণ: ওয়েদার অ্যাপ

একটি সাধারণ ওয়েদার অ্যাপে কীভাবে বিভিন্ন কন্ডিশনাল স্টেটমেন্ট ব্যবহার করা হয় দেখা যাক:

```javascript
function setWeather(weatherType, temperature) {
    let message = "";
    
    // if...else if...else ব্যবহার করে মূল ওয়েদার টাইপ সিলেক্ট করা
    if (weatherType === "sunny") {
        message = "It is nice and sunny outside today.";
        
        // নেস্টেড if (একটি if-এর ভিতরে আরেকটি if)
        if (temperature >= 86) {
            message += " REALLY HOT! Use sunscreen.";
        } else {
            message += " Let's go to the beach!";
        }
    } else if (weatherType === "rainy") {
        message = "Rain is falling outside; take an umbrella.";
    } else if (weatherType === "snowing") {
        message = "The snow is coming down — it is freezing!";
    } else {
        message = "Check weather updates.";
    }
    
    // switch ব্যবহার করে বিশেষ সুপারিশ যোগ করা
    switch (weatherType) {
        case "sunny":
            message += " ☀️";
            break;
        case "rainy":
            message += " 🌧️";
            break;
        case "snowing":
            message += " ❄️";
            break;
    }
    
    return message;
}

// লুপ ব্যবহার করে একসাথে অনেক শহরের ওয়েদার চেক করা
const cities = ["Dhaka", "Chittagong", "Sylhet"];
for (const city of cities) {
    console.log(`Weather in ${city}:`);
    // প্রতিটি শহরের জন্য ওয়েদার চেক করার কোড
}
```

✅ বেস্ট প্র্যাকটিস ও সতর্কতা

· কোড রিডেবল রাখুন: বেশি গভীর নেস্টেড if স্টেটমেন্ট এড়িয়ে চলুন (৩ স্তরের বেশি না)। জটিল লজিক আলাদা ফাংশনে ভাগ করুন।
· স্ট্রিক্ট ইকুয়ালিটি: == এর বদলে === ব্যবহার করুন যাতে টাইপ কনভার্সন জনিত সমস্যা না হয়।
· সঠিক অপারেটর:
  · && (AND) - সবগুলো শর্ত সত্য হতে হবে
  · || (OR) - যেকোনো একটি শর্ত সত্য হলেই হবে
· switch এ break ভুলবেন না: না হলে অপ্রত্যাশিত ফলাফল পেতে পারেন।
· লুপে ইনফিনিটি লুপ এড়ান: while লুপে কাউন্টার ইনক্রিমেন্ট করা নিশ্চিত করুন।
· টারনারি অপারেটর সরল রাখুন: জটিল লজিকের জন্য if...else ব্যবহার করাই ভালো।

📊 তুলনামূলক সারসংক্ষেপ

কন্ডিশনাল স্টেটমেন্টস:

· if - একক শর্ত চেক করতে
· if...else - দুইটি বিকল্প পথের মধ্যে বাছাই করতে
· if...else if...else - একাধিক শর্ত ক্রমানুসারে চেক করতে
· switch - একটি মান অনেকগুলো কেসের সাথে মিলাতে
· ternary - দ্রুত দুই-পথের সিদ্ধান্ত ও মান অ্যাসাইন করতে

লুপস:

· for - নির্দিষ্ট সংখ্যক পুনরাবৃত্তি
· while - শর্ত সত্য হওয়া পর্যন্ত
· do...while - অন্তত একবার রান নিশ্চিত করে
· for...of - অ্যারে/ইটারেবলের আইটেম নিয়ে কাজ
· for...in - অবজেক্টের প্রপার্টি নিয়ে কাজ

🎓 শেষ কথাঃ

কন্ডিশনাল স্টেটমেন্টস ও লুপস জাভাস্ক্রিপ্ট প্রোগ্রামিংয়ের ভিত্তি। এগুলোর দক্ষ ব্যবহার আপনাকে আরও ইফেক্টিভ, রিডেবল এবং মেইনটেইনেবল কোড লিখতে সাহায্য করবে।

প্র্যাকটিসের জন্য আইডিয়া:

· একটি গ্রেড ক্যালকুলেটর তৈরি করুন (if...else if...else ব্যবহার করে)
· একটি শপিং কার্টের সব আইটেমের দাম যোগ করুন (for বা for...of লুপ ব্যবহার করে)
· ইউজারের বয়স ও দেশভিত্তিক বিভিন্ন মেসেজ দেখান (switch ও if একসাথে ব্যবহার করে)

প্রোগ্রামিং একটি ব্যবহারিক দক্ষতা - তাই বেশি বেশি কোড লিখুন, এক্সপেরিমেন্ট করুন, আর শেখার আনন্দ নিন!
